إزاي الصفحة دي بتشتغل؟

  1. الصفحة (JavaScript) بتبعت طلب fetch للـ Web API.
  2. الـ Controller بيستقبل الطلب وينده على الـ Application (Service).
  3. الـ Service بيجيب البيانات من الـ Repository وبينده على الـ Domain (قواعد الحجز والرسوم).
  4. الرد بيرجع بنفس الطريق، وبيتعرض هنا. شوف جدول "سجل الطلبات" تحت.

1. التجارب المنشورة

GET /api/experiences

2. احجز:

POST /api/bookings/preview (مفيش حاجة بتتحفظ)

3. حجوزاتي

GET /api/bookings?touristId=...

4. سجل الطلبات (Network log)
